# Ultra Yavaş Çay Sözleri Üretici

## Bu Nedir?

Bu, insanlık tarihinin en ciddi, en akademik ve en gereksiz projesidir. Çay içmenin felsefi derinliklerini keşfetmek için tasarlanmıştır. Her söz, evrenin termodinamik yasalarına uygun olarak tam 3.7 saniye bekletilir. Daha hızlı olursa çay küser.

## Nasıl Çalışır?

Kod, rastgele çay sözleri üretir ve her birini o kadar yavaş söyler ki, çay demlenmeden bitmez. Gerçekten çalışır. Deneyin.

## Kurulum

```bash
pip install time random
python cay_sozleri.py
```

(Zaten built-in modüller, saçmalama.)

## Uyarı

Bu kod sonsuza kadar çalışabilir. Ctrl+C ile kurtulun. Yoksa çay sizi yutar.
